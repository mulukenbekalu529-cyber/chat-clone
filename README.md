# ChatGPT Clone

A full-stack chat app where users register, log in, and chat with an AI assistant that answers and questions. Conversations are saved in a database.

## Live Links
- App (Frontend, Netlify): https://chat-clon.netlify.app
- Backend API (Render): https://chat-clone-mlrm.onrender.com

## Features
- User registration and login (JWT authentication)
- AI responses using Google Gemini
- Chat history saved in a MySQL database

## Tech Stack
- Frontend: React, hosted on Netlify
- Backend: Node.js and Express, hosted on Render
- Database: MySQL, hosted on Aiven
- AI: Google Gemini

## Note
The backend is on a free plan, so the first load can take up to a minute.
